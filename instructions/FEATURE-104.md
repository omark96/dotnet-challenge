# FEATURE-104 – Filter users by status

**Type:** Feature

## Background

Administrators need to focus on active or inactive users separately when working with a large directory.

## Acceptance criteria

- The user list offers **All**, **Active**, and **Inactive** choices.
- The selected status can be used together with the existing name search.
- The selected state is clearly visible to the administrator.
- Changing the selection updates the list without a page refresh.
- Existing user directory functions continue to work.
